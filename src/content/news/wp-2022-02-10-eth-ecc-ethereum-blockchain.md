INFONET Lab, GIST has set up ETH-ECC Ethereum blockchain. Any one around the world can connect with ETH-ECC. Metamask Connection and Explorer are also implemented for this network.

ETH-ECC Network Setup Steps:

1. Environment setup and download ETH-ECC
   1. Editor installation
   2. Download ETH-ECC
2. Configuration of ETH-ECC environment for genesis node
3. Initialize genesis block for ETH-ECC network
4. Run ETH-ECC node
5. Peer nodes to the ETH-ECC network
6. MetaMask configuration for ETH-ECC
7. Explorer view of ETH-ECC
8. ETH-ECC network testing
